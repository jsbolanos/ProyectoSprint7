# Proyecto Sprint 7 - Análisis de anuncios de vehículos

Aplicación web desarrollada con Python, Pandas, Plotly y Streamlit para explorar datos de anuncios de vehículos.

La aplicación permite visualizar:

- La distribución del odómetro mediante un histograma.
- La relación entre el odómetro y el precio mediante un gráfico de dispersión.
